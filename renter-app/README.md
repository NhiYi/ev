# Renter App (React + Vite)

## Quick start
1. Create folder `renter-app` and paste files from this document.
2. Copy `.vite.env.example` to `.env`
3. Set:
   VITE_API_BASE_URL=http://localhost:8000/api
4. Install dependencies:
   npm install
5. Start dev:
   npm run dev

API → goes through gateway `/api/*`
